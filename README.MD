# TheDotNetAPI (Study)

- This Repo has the main objective to showcase how a Swagger API with PostgresSQL integration works (using .NET 9.0)

### The following resources where used in the (re)making of this project

- Docker
- PostgresSQL
- Visual Studio Community Edition
- GIT
- Github
- Dbeaver

- The database and Docker where used locally on my own home server, making use of Ubuntu Server 22.04.
